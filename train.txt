I've written the full training framework in a new training/ folder, about 1,900 lines. It runs end to end: prepare data → train in PyTorch → export ONNX → build a TensorRT engine → run live on the Jetson.

Tested on this laptop's CPU. python selftest.py runs the whole pipeline on generated fake audio in under a minute and printed ALL CHECKS PASSED (12/12). It does not show the model learns or reaches the PS targets; only training on your real data will show that.

The model's size matches the paper: 23,669 parameters single-mic against the published 23.7 K, and 24,389 with Mic 2 added. The exported ONNX file gives the same output as PyTorch (differences around 0.0000001), and runs one frame in about 4 ms on this CPU against a 16 ms budget.

Not tested:

Jetson side: build_engine.sh (TensorRT) and realtime.py with a real mic interface. There's no Jetson here, so only the resampler in realtime.py was checked.
GPU training: everything ran on CPU only.
PESQ: the metric library won't build on Windows, so PESQ shows as blank here. It installs normally on Linux or Kaggle.
What's in the folder
Step	File	What it does
0	selftest.py	Checks everything works. Run first
1	configs/sanity_voicebank.yaml	Trains plain GTCRN on a public benchmark. PESQ should come out near the paper's 2.87; if not, the code has a bug
2	build_index.py	Scans your data drive once and lists every usable file
3	train.py	Trains the model and saves the best checkpoint
4	evaluate.py	SNR, PESQ and STOI at each input noise level, and where each PS target is first met
5	prune.py, quantize_onnx.py	Shrinks the model (the PS's pruning and quantisation)
6	export_onnx.py	Makes the ONNX file, and refuses to finish unless it matches PyTorch
7	jetson/build_engine.sh	On the Jetson: ONNX → TensorRT engine, plus a latency benchmark
8	jetson/realtime.py	On the Jetson: live mics in, clean voice out. Press ENTER to switch the model on/off for the demo
All settings are in one file, configs/base.yaml. That includes your dataset folders, noise mix, SNR range, loss weights and training settings.

python selftest.py

python train.py configs/base.yaml
python evaluate.py runs/gtcrn_dualmic-XXXX/best.pt

Then on the Jetson:
