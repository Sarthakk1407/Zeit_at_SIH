## Rebuild

```bash
python make_pcb.py
python build_deck.py && python qa_geometry.py && python render_preview.py
```

`make_pcb.py` only needs rerunning if the PCB drawing changes. All three of the
second line must come back clean: no text-fit warnings, `problems: 0`, six PNGs.
Delete the stale `preview/slide-7.png` after rendering.

If `ZEIT_SIH2026_Idea.pptx` is open in PowerPoint, `build_deck.py` writes
`ZEIT_SIH2026_Idea_v2.pptx` (and upwards) instead of failing.

Dependencies: `python-pptx`, `Pillow`.

## Constraints taken from the template

- **Six slides maximum, including the title slide.** The template's instruction
  slide (the seventh) is removed at the end of the build.
- **The idea-detail pointers must not be changed.** Every pointer is read out of
  the template at build time and re-emitted **verbatim** as a section label.
  `qa_geometry.py` will not catch a dropped pointer, so the check is in the
  build: if a pointer index moves, the slide fails loudly.
- **Points, diagrams and infographics rather than paragraphs.**

## ⚠️ Claims on the deck that disagree with `synthetic_generator/`

The deck text was written against the capture *plan*. The 7 Sep 2026 range trip
(`synthetic_generator/PHASES.md` Phase 1) did not achieve all of it. A technical
judge who reads the repository will find these; fix the strings or the data
before submitting.

| On the deck | Where | What actually happened |
|---|---|---|
| "96 kHz · 24-bit" | slide 4 chain and `slide_field.py` | Recorded at **48 kHz** / 24-bit |
| "Calibrated to absolute dB SPL with a reference tone" / "Calibrate — absolute dB SPL" / "Calibrated gunshot data" | `slide_field.py`, slide 4, slide 2 diff 4 | **No calibration tone was recorded** — levels are dBFS |
| "Staggered gain 18–24 dB apart — the cold channel survives the clip" | `slide_field.py`, slide 4 risks | Channel 2 (MacBook mic) **clipped** and was gated; the two-channel measurement did not survive |
| "54 quantities measured per shot" | slide 4, `slide_field.py` | `analyze.py` and every doc say **16** |
| Gunshot data | slides 2, 4 | Air gun with target impact — not a firearm muzzle blast |

## Design rules

- **Text is near-black throughout.** `INK`, `STEEL` and `LABEL` are black;
  hierarchy comes from weight, size and capitalisation. `MID` is a **stroke
  colour only** — never use it for type. `RUST` is an alias for the primary
  accent, now `BLUE`; the categorical hues are `GREEN`, `ORANGE`, `PURPLE`,
  `CRIMSON`, `TEAL`, each with an `_F` fill tint.
- **The links are built, not pasted.** `link_block()` emits real PowerPoint
  hyperlinks on slides 2 and 3, and slide 6 prints the deployment URLs. Anything
  added by hand in PowerPoint is lost the next time `build_deck.py` runs.
- **Slide 1 is signed off.** Refinements do not touch it.

## A note on QA

LibreOffice is not installed in this environment, so `soffice --convert-to pdf`
is unavailable. Substitutes:

- `deckkit.check_fit()` measures every string against the **real Arial metrics**
  from `C:/Windows/Fonts` and reports anything that cannot fit.
- `qa_geometry.py` reports content outside the safe area, collisions with the
  template's logo and footer bar, overlapping text boxes, and text wider than
  its container.
- `render_preview.py` draws the slides from the shape tree so the layout can be
  looked at. It approximates PowerPoint's renderer — treat it as a layout check,
  not a colour proof.
